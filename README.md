# privacy-policy

Public privacy policies for my iOS apps, served with GitHub Pages.

| Page | URL |
| --- | --- |
| Index | https://ichola.github.io/privacy-policy/ |
| ChalkPrint | https://ichola.github.io/privacy-policy/chalkprint.html |
| Second Reading | https://ichola.github.io/privacy-policy/second-reading.html |

Use the per-app URL in App Store Connect (App Privacy → Privacy Policy URL) and in the app's own Settings screen.

## Enabling Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`. It takes a minute or two to go live the first time.

## Editing

Plain static HTML, no build step. Each policy is one file sharing `style.css`. When an app's data practices change, update its page **and** the "Last updated" date before the new version ships.
